# Exam1_FrontEnd-Backend

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы разработан многостраничный HTML/CSS-сайт учебного интернет-магазина. Проект включает главную страницу, каталог товаров и страницу контактов. 

В проекте продемонстрировано использование семантической разметки, CSS-переменных, Flexbox, CSS Grid, базового позиционирования и методологии БЭМ.

## Ссылка на опубликованный проект

GitHub Pages: [https://darkyoutube.github.io/Exam1_FrontEnd-Backend/](https://darkyoutube.github.io/Exam1_FrontEnd-Backend/)

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3 (переменные, Flexbox, Grid, позиционирование);
- JavaScript (базовая логика модального окна и валидации формы);
- Методология БЭМ (именование классов);
- Git и GitHub.

## Структура проекта

- `index.html` – главная страница (hero-блок, преимущества, популярные товары);
- `catalog.html` – каталог товаров (сетка карточек, фильтры);
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – файл JavaScript;
- `images/` – папка для изображений;
- `README.md` – описание проекта;
- `.gitignore` – список файлов, исключённых из Git.

## Реализованные элементы

- **Семантика:** используются теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- **Навигация:** единое меню на всех страницах, якорные ссылки (`#popular`, `#advantages`, `#contacts`).
- **Карточки товаров:** оформлены по БЭМ, используются модификаторы (`product-card--featured`).
- **Форма:** форма оформления заявки, валидация через HTML5 (`required`, `pattern`, `minlength`) и JS.
- **Модальное окно:** реализовано через нативный тег `<dialog>`.
- **CSS:** внешний файл, переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- **Flex/Grid:** Flexbox для навигации и карточек, Grid для сетки товаров и макета каталога.
