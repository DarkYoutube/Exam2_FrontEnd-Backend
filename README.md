# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Проект представляет собой версию сайта интернет-магазина, разработанную с использованием Bootstrap.

## Практическая работа 9 и 10
Реализовано:
- Подключение Bootstrap через CDN.
- Главная страница на Bootstrap-сетке (hero-блок, карточки).
- Единая навигация (navbar) на всех страницах.
- Компоненты `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `table`.
